# 粒子聚字演示（ParticleToText）设计

- 日期：2026-11-11
- 位置：`samples/ParticleToText/`
- 状态：待批准（评审已过一轮，见 §11 决议记录）
- 决策人：用户（形态/路线/取舍），实现者（工程细节）

---

## 1. 意图与为什么

做一个**独立的 .NET 8 WPF 演示程序**：几千个离散粒子从散落状态收拢，聚成用户输入的任意文字；
换句时散开、重新聚拢。它要证明两件事——"离散"（看得见每个粒子，不是贴图或描边）和"任意"
（中文、英文、数字、符号，打什么成什么）。

为什么做成 samples 下的独立工程：这是可复用的观感原型，不是 HUD 的功能需求。它不接入
`MirrorpondHUD` 的卡片/插件体系，也不引用宿主任何程序集；将来若要把粒子字做成卡片，
直接把 `Core/` 搬过去即可。

## 2. 目标

1. 输入框打任意文字，回车后粒子聚成该文字；连续换句不残留、不闪烁。
2. 观感：深色底、冷色光点、聚合时字缘发亮、有轻微拖尾与辉光；静止时粒子仍在呼吸，不死板。
3. 默认参数下 1600×900（100% 缩放）窗口稳定 60fps（帧耗时 < 16.7ms）。
4. 右侧折叠面板可调粒子数、辉光、拖尾、字号、抖动、配色、采样模式；设置落盘并在下次启动读回。
5. 三条命令行验证通道：`--selftest`、`--shot`、`--bench`，可在无人工干预下自证。
6. 中文 README，说明原理、文件地图、参数含义与已知限制。

## 3. 非目标

- 不做 3D、不做 GPU 计算（Compute Shader / D3D 互操作）、不做视频导出。
- 不接入 MirrorpondHUD 卡片系统，不新增插件、不改宿主代码、不改根 `csproj`。
- 不做多窗口、托盘、开机自启。
- 不做粒子物理碰撞（粒子之间互不作用）。

## 4. 反目标（做出来也算失败）

- 聚成字后仍抖到不可辨认。**可读性优先于特效**：任何参数组合下文字轮廓都必须清晰。
- 为特效引入第三方包（SkiaSharp、SharpDX、ImageSharp 等一律不许）。
- 用 `catch { }` 吞掉采样/落盘/渲染失败；失败必须出现在界面上或日志里。
- 粒子数与帧率靠"降采样到糊"糊弄过去，却不告诉用户已经降级。

## 6. 已定的做法

### 6.1 工程形态

`samples/ParticleToText/ParticleToText.csproj`：`WinExe` + `UseWPF`，`EnableDefaultApplicationDefinition=true`
（继承的 `false` 要在本工程覆盖回来，否则 `App.xaml` 不会被当成入口），`app.manifest` 开 PerMonitorV2。
`AssemblyName`/`RootNamespace` 都是 `ParticleToText`。不含任何 `PackageReference`。
三种启动模式照 `ContourLine/App.xaml.cs` 的写法（`--selftest` / `--shot` / `--bench` 都在 `OnStartup` 里分流，
`ShutdownMode.OnExplicitShutdown` 撑住消息循环）。

### 6.2 取点：两条采样路径

两条路产出**同一结构**：`List<Vector>`（DIP 坐标，原点在画布中心）+ 包围盒 + **实测点数**。
**点结构只带坐标，不带权重通道**（见 §11 D2）；"字缘发亮"由加色饱和与辉光自然产生，不做逐点距离变换。

- **掩码采样（默认，路线 A）**：`FormattedText` → `RenderTargetBitmap`（离屏、灰色、约 220px 字高）
  → 按步长扫 alpha，超过阈值即候选点 → 洗牌后取前 N 个 → 映射回画布坐标。
  步长按"目标粒子数 ÷ 覆盖率"反推，扫两遍：第一遍估算覆盖率，第二遍定步长。
- **几何拒绝采样（可选，路线 B）**：`FormattedText.BuildGeometry` 得轮廓，在包围盒内撒候选点，
  用 `Geometry.FillContains` 筛字内点。点分布更均匀；代价是首帧多约 100ms（数万次 `FillContains`）。

**粒子数是目标值，不是硬指标**：候选点少于设定值时，如实采用实测点数，底栏显示实测值并提示
「候选点不足」，**不得重复补点**（同一位置叠加会烧成亮斑，直接违背"离散"）。

采样在后台线程完成，`Freeze()` 后交给 UI 线程；带**代次计数**，晚归的旧代结果直接丢弃
（AGENTS.md §6.3 的模式）。采样失败（空文字、字体缺字、位图为空）→ 状态行报错 + 保留上一句，
不得清空画面。

### 6.3 渲染：能量缓冲 + 帧衰减 + 低分辨率辉光

不建任何 WPF 视觉对象（没有 Ellipse、没有 DrawingVisual），整个画面是一块 `WriteableBitmap`：

1. 维护 `uint[]` 能量缓冲（BGRA 打包），尺寸 = **物理像素**（DIP × DPI 缩放，PerMonitorV2 下会变）。
2. 每帧：全缓冲乘衰减系数（位移实现，约 `(v*230)>>8`）→ 得到拖尾；而不是清屏。
3. 粒子按加色叠加小核：中心 1 像素满强度，周围 3×3 权重衰减。粒子坐标是 DIP，落像素时乘 DPI 缩放。
4. 辉光：把能量缓冲 1/4 降采样 → 两遍盒式模糊 → 双线性放大后加性混回主缓冲。
5. `WritePixels` 一次上屏。

**单位与降级（§11 D1）**：一切按**物理像素**判定。物理像素数超过 **2 300 000**（约 1600×900 的 1.6 倍，
对应 125% 缩放下的 1600×900 DIP 窗口）时，能量缓冲自动降到半分辨率累积、再放大上屏，
底栏常亮「半分辨率」；不得静默降级。**帧率优先于锐度**是用户拍板的取舍。

### 6.4 运动

- 每粒子：`Pos`、`Vel`、`Target`、`Hue jitter`、`Settled`。
- 弹簧：`Vel += (Target - Pos) * k * dt`，再乘阻尼；`k` 与阻尼按"约 0.6–1.2s 到位"调参。
- 换句：先给所有粒子一个从旧质心向外的爆散冲量（可关），再重新分配目标点。
- 目标分配默认**洗牌随机**（粒子穿插飞行，视觉上更"离散"）；面板提供"就近分配"选项。
- 到位后加低幅值噪声（呼吸），幅值 ≤ 0.8px，保证可读性。

### 6.5 交互与界面

- 全屏画布 + 顶部居中输入框：占位文字「输入文字，回车成型」，与输入内容同字号同位置，
  无边框、半透明底，失焦后淡出到 30% 不透明度。
- 快捷键：`Enter` 成型、`Esc` 退出、`Tab` 折叠/展开右侧面板、`Ctrl+R` 重放当前句。
- **字号是上限，不是死值（§11 D5）**：文字放不下时自动缩字号直到整句进入画布（留 6% 边距），
  底栏提示「已自动缩放」；面板显示的是用户设定值，底栏显示实际生效值。不裁切、不折行。
- 窗口尺寸或 DPI 变化：180ms 防抖后重新采样（不按比例拉伸目标点，避免字形变形）。
- 右侧面板默认收起，展开后是清单式滑杆/勾选/配色胶囊（照 `ContourLine` 的 `AppearancePanel` 写法）：
  粒子数、字号、辉光强度、拖尾衰减、抖动、爆散、配色、采样模式、就近分配。
- 底栏：帧耗时（最近 8 帧均值）、实测粒子数、当前采样模式，以及**降级/自动缩放/失败状态行**。

### 6.6 设置与失败可见

- 设置写 `%LOCALAPPDATA%\ParticleToText\settings.json`：先写临时文件再 `File.Replace`，失败回退
  Copy+Move；读回失败或损坏 → 用默认值 + 状态行明示，不静默。
- 设置模型用**公开字段**（仓库 DTO 风格），`System.Text.Json` 要开 `IncludeFields`；
  这是 `ContourLine` 已经踩过的坑（README 有记录），必须复现同样的防护。
- 日志：`%LOCALAPPDATA%\ParticleToText\particle.log`，只在采样/渲染/落盘失败时写，带时间戳。

### 6.7 三条验证通道

| 命令 | 行为 | 退出码 |
| --- | --- | --- |
| `--selftest` | 约 12 项断言（采样点数、点在包围盒内、空文字拒绝、洗牌覆盖、衰减数学、加色饱和、DPI 映射、设置往返、损坏设置兜底、字体回退、半分辨率判定、粒子数夹取） | 失败项数 |
| `--shot out.png [--size WxH] [--text 文案]` | 离屏渲染一帧存 PNG，不出窗口 | 0 / 1 |
| `--bench N` | 真跑 N 秒动画，报平均/中位/P95/最差帧耗时与粒子数，剔除预热帧 | 0 / 1 |

**`--shot` 必须可复现（§11 D3）**：固定使用默认设置（**不读**用户落盘配置），文字取 `--text` 或缺省
「镜潭一览」；等粒子聚拢到位（轮询"平均剩余距离 < 0.5px"，最多 3 秒）再取帧；只拍画布，
**不含**输入框、面板、底栏；DPI 固定按 1:1 离屏渲染。这样别的机器上拍到的图不会因为用户的
半分辨率/小字号/大抖动设置而变成糊图，把"聚字坏了"误报成缺陷。

## 8. 性能预算

按 **100% 缩放、1600×900 物理像素、8000 粒子** 计：

| 项 | 预算 |
| --- | --- |
| 帧衰减（全分辨率 1.44M 像素） | ≤ 3.0ms |
| 粒子加色（8000 × 9 像素） | ≤ 1.0ms |
| 辉光（1/4 缓冲模糊 + 上采样） | ≤ 3.0ms |
| `WritePixels` | ≤ 1.5ms |
| 弹簧积分 + 噪声 | ≤ 0.5ms |
| **合计** | **≤ 9ms（留 40% 余量）** |
| 采样（换句一次，后台） | 掩码 ≤ 80ms，几何 ≤ 250ms |

其它缩放下不承诺绝对毫秒数，只承诺"超过 230 万物理像素即降半分辨率"这条可判定规则。

## 9. 验收标准

1. `dotnet build samples\ParticleToText\ParticleToText.csproj -c Release` **0 警告 0 错误**。
2. `ParticleToText.exe --selftest` 退出码 0。
3. `ParticleToText.exe --shot out.png --text "镜潭一览"` 产出 PNG，图中文字清晰可辨。
4. `ParticleToText.exe --bench 6` 稳态平均帧耗时 < 16.7ms（100% 缩放、1600×900、8000 粒子）。
5. 根工程 `dotnet build -c Release` 不受影响（samples 已被排除）。
6. README 覆盖：运行方式、原理流水线、文件地图、参数含义、已知限制。

## 11. 决议记录（2026-11-11 评审后）

| 编号 | 问题 | 决议 |
| --- | --- | --- |
| D1 | 预算/降级阈值按 DIP 还是物理像素 | 一律物理像素；阈值 230 万；高 DPI 下**帧率优先**，自动半分辨率并在底栏明示；预算与验收在 100% 缩放下测 |
| D2 | "字缘发亮"是否要逐点权重通道 | 不要。点结构只带坐标，靠加色饱和 + 辉光自然产生；几何模式的"按笔画距离渐变"从首版撤下 |
| D3 | `--shot` 拍什么、用谁的设置 | 固定默认设置、等粒子到位（≤3s）、只拍画布、DPI 1:1，保证跨机器可复现 |
| D4 | 粒子数是目标还是硬指标 | 目标值。候选点不足时如实采用实测点数 + 底栏「候选点不足」，不重复补点 |
| D5 | 字号语义与放不下时的行为 | 字号是上限；自动缩到放得下（6% 边距），底栏提示「已自动缩放」；resize/DPI 变化防抖 180ms 后重采样 |
