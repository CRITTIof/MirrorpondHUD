# 《明日方舟：终末地》工业风动效调研

> 目的：把《终末地》的动效规律（时长、缓动、反馈、编排、循环、降级）拆成**可执行参数**，并给出落到 MirrorpondHUD 的建议。
> 边界：只谈**时间维度**。颜色、形状、排版、纹样见姊妹篇 [`endfield.md`](endfield.md)。
> 判据：**美观优先**，实现成本不进筛选器；成本只在 §16 决定先后顺序。

---

## 1. 结论先行

五条原则（规范原文的压缩）：

| # | 原则 | 含义 | 落到参数 |
|---|---|---|---|
| 1 | **短** | 交互反馈在 0.2–0.3 秒内完成 | 200ms 换色、300ms 位移 |
| 2 | **硬** | 用位移、擦入、形变、明暗反转；**不用弹跳、回弹、持续漂浮** | 无过冲曲线 |
| 3 | **有因果** | 动效解释「什么变了、从哪来」：底块从左滑入、文字让位给箭头、遮罩向一侧退出 | 位移 + 让位 |
| 4 | **戏剧性只给入场** | 闪烁点亮、加载页只在进入时出现**一次**，日常交互保持安静 | 600ms 档只给入场 |
| 5 | **可以关** | 尊重系统「减少动态效果」 | 时长归零、停在终态 |

六个最该记住的数字：

| 数字 | 含义 | 证据 |
|---|---|---|
| **300ms ×119 条 / 200ms ×63 条** | 官网样式表里过渡时长的分布：九成集中在 0.2s 与 0.3s | 实测（图解统计） |
| **进 300 / 出 200** | 进出**不对称**：来的时候看得清从哪来，走的时候不挡路 | 规范 |
| **4px / 8px** | 位移只提示方向：贴触发元素 4px，大面积与贴视口 8px | 规范 |
| **50–100ms** | 一组东西逐项入场的错开量；最多错开前 5–6 项，**整组 ≤600ms** | 规范 |
| **200ms** | 状态记号（勾、圆点、括号、选中指示滑动）的进出 | 规范 |
| **2.4s** | 开屏页「充填 → 铺满 → 淡出」全程；唯一「为了播完动画而等」的地方 | 实测（2026-10-14） |

## 3. 时长：两档吃掉九成

| 令牌 | 值 | 用途 | 官网出现次数 |
|---|---|---|---|
| `duration-instant` | 50ms | 按下的即时反馈 | 1 |
| `duration-fast` | 200ms | 颜色、透明度变化 | **63** |
| `duration-base` | 300ms | **位移、展开、形变（默认档）** | **119** |
| `duration-slow` | 400ms | 较大面积的移动 | 8 |
| `duration-slower` | 600ms | 入场 | 6（0.5s 与 0.6s 合计） |

结论：**默认就是 `duration-base` + `ease-standard`，不确定时不要调**（规范原文）。超过 0.6s 的只有个别入场与循环动画。

对照参考（云游戏页，实测）：过渡最常见 0.15s（14 次），动画最常见 0.16s（34 次）——**两套载体各有自己的主频，但档位不变**。

## 4. 缓动：四档

| 令牌 | 值 | 用途 |
|---|---|---|
| `ease-standard` | `ease` | 默认；官网多数过渡没写缓动，就是浏览器默认值 |
| `ease-emphasis` | `ease-in-out` | 往返位移、面板展开 |
| `ease-exit` | `ease-out` | 入场、从屏幕外进入 |
| `ease-linear` | `linear` | 旋转、跑马灯、闪烁 |

## 5. 交互反馈的五个套路

### 5.1 悬停：换色，不上浮
| 控件 | 悬停时 |
|---|---|
| 深色按钮 | 底 `#383838 → #484848`，字 `#EEEEEE → 白`；圆角 2px → 6px |
| 浅色按钮 | 底白 → `#F0F0F0` |
| 导航项（云游戏页） | 深色项白 20% → 30%，字 `#BFBFBF → 白`；亮色项 `#EEEEEE → 品牌黄`；圆角不变（0.15s） |
| 翻页钮 | 底 `#FAFAFA → 信号黄` |
| 导航图标 | `#D9D9D9 → #858585` |
| 页签 | 底透明 → `#F3F3F3` |
| 主行动块（黑） | 黄色底层淡入，文字由白变墨 |
| 分享按钮 | 底变墨黑，图标变黄 |

**没有任何控件在悬停时放大、上浮或加重阴影。** 云游戏页的导航项悬停时圆角也不跟着变。

### 5.2 悬停：竖条变箭头

官网首页的深色按钮左侧有一条 3px 黄竖条，悬停时**变成向右的三角并右移约 10px**——「这里可以前往」的暗示。

做法：同一个伪元素在两个 `clip-path` 多边形之间插值。

```css
/* 竖条 */
clip-path: polygon(0 0, 25% 0, 25% 100%, 0 100%);
/* 箭头：四个点，后两点重合，保证顶点数与上一条相同 */
clip-path: polygon(0 20%, 100% 50%, 0 80%, 0 80%);
transform: translateX(0.625rem);
transition: clip-path var(--duration-base) var(--ease-standard),
            transform var(--duration-base) var(--ease-standard);
```

关键约束：**两个多边形的顶点数必须相同**才能插值。

### 5.3 激活：让位

页签被选中时，**文字向左平移一小段，右侧淡入一个圆形箭头**；导航轨悬停时一块灰底向右展开、文字随之出现。
共同点：**新元素出现时，旧元素挪开一点给它腾位置**，而不是凭空叠上去。

### 5.4 按下：只加深一档，不缩小

按下态只换更深的颜色（黄 → `#EEEA00`，深灰 → `#282828`），**不缩小**。
云游戏页顶栏的深色导航项按下是白 15%，比平时的 20% 还淡——压在深色底上，**淡就是暗**。

### 5.5 关闭：转 90°

弹窗关闭图标悬停旋转 90°。规范注明这是**全站少有的旋转动效**——也就是说旋转本身就是稀缺资源。

## 6. 状态记号要有过渡

勾、圆点、细线、括号这类「记号」，出现时**不硬切**：让画面看得出「是变过来的」。记号是小件，进出都用 `duration-fast`（200ms）。

| 控件 | 什么变了 | 怎么动 |
|---|---|---|
| 复选 / 单选 | 勾、半选短横、圆点 | 淡入淡出 200ms，与方格换底色同时走 |
| 输入类 | 焦点进 / 出 | **聚焦墨线从左往右擦出 300ms；失焦缩回 200ms** |
| 滑块 | 按住时的细线、改值后的位置 | 细线淡入淡出；滑块头与走过段滑过去 200ms；**拖动、点轨道时不过渡** |
| 步骤条 | 连接线、节点 | 线的墨色从起点充到头 300ms；节点换色 200ms |
| 角括号 | 选中 / 拖入时四角的括号 | **八段短线各自从角顶点伸到满长 200ms；消失是直接消失** |
| 验证码 | 填入的那一位 | 字从透明到墨 200ms；粘贴整串时各格一起到 |

一个易错点：焦点线用**裁切**从左擦出，**不用缩放**——缩放会把四条边压扁、角上变细。

## 7. 进出不对称与方向位移

### 7.1 不对称

**进入用 `duration-base`（300ms），退出用 `duration-fast`（200ms）**：来的时候看得清从哪来，走的时候不挡路。
记号、文字提示这类小件，**进出都用 200ms**。

### 7.2 位移只提示方向

| 令牌 | 值 | 用途 |
|---|---|---|
| `--motion-shift` | 4px | 贴着触发元素出来的浮层：菜单、气泡卡、悬浮卡、文字提示 |
| `--motion-shift-lg` | 8px | 大面积、贴视口边缘：弹窗、全屏菜单栏目、底部轻提示、完成横幅标题 |

三条纪律：

1. **位移只写在进场的起点上，退场只淡出**——走的时候不用再交代「回哪去」；
2. **位移只是提示方向，不是滑行**：距离再长就成了「飞进来」；
3. **透明度与位移各走各的时长**：透明度 200ms、位移 300ms `ease-out` —— 面板因此「先看得清、再落稳」，
   「进出不对称」也由此自然产生，不必另写退场时长。

| 浮层 | 从哪来 | 怎么动 |
|---|---|---|
| 菜单 / 下拉 / 气泡 / 悬浮卡 | 触发元素那一侧 4px | 淡入 200ms，位移 300ms；退场只淡出 200ms |
| 弹窗 / 确认框 | 下方 8px | 遮罩淡入 200；面板淡入 200 + 位移 300；退场只淡出；**不放大** |
| 底部轻提示 | 下方 8px | 淡入 200 + 位移 300；退场只淡出 |
| 全屏菜单 | 整层原地淡入；栏目从左 8px | 整层 200ms；栏目每条 300ms 错开；退场整层淡出 200ms |
| 文字提示 | 触发元素那一侧 4px | 小件：淡入与位移都 200ms；键盘聚焦、从相邻提示移过来时**立刻出现** |

## 8. 编排：错开与入场

### 8.1 错开

- 每项错开 **50–100ms**；
- **最多错开前五六项**，后面的一起到；
- **整组从第一项动到最后一项停下，不超过 600ms**；
- **只用在「整屏换掉」这样的入场上**。列表、时间线、步骤条**不做**默认的逐项入场。

例（全屏菜单栏目）：第一项等 100ms（整层淡入过半），之后每项晚 50ms，第六项起一起到（350ms），全程 550ms。

### 8.2 入场表

| 元素 | 怎么动 | 多久 |
|---|---|---|
| 分节标题 | 灰块从左滑入，块内箭头 −45° 转正，随后文字淡入；顺序「块 → 箭头 → 字」，各错开约 100ms | 各 300ms |
| 完成横幅 | 整块从左擦入；标题组从左 8px 淡入归位，行动淡入，都比色带晚 200ms | 色带 300ms；总 500ms |
| 方括号标题 | 两个括号淡入，名称晚 100ms 淡入；**不位移**（行内文字做不了） | 各 300ms；总 400ms |
| 小型面积图 | 整张从左擦出；同屏几张一起画，**不逐张错开** | 600ms |
| 空状态 | 整块淡入，不位移——只为不「啪」地出现 | 300ms |
| 滚动数字 | 从 0 滚到终值，先快后慢；宽度由终值占着；值后来变了直接换不再滚 | 600ms |
| 页头 | 微文字 → 标题 → 说明，各自从左 8px 淡入归位，依次晚 100ms | 各 300ms；总 500ms |

三条边界：**进视口才播的播一次**（滚走再回来不重播）；**能点的东西不做位移入场**（位置在动的不好点）；**一开始就在的不播**。

## 9. 展开、增删与补位

### 9.1 收放：按高度，不量高度

外层是只有一行的网格，行高在 `0fr` 与 `1fr` 之间过渡，内层裁掉放不下的那一截。
展开起点写在 `@starting-style` 里：**展开到一半又收起，过渡从半路折回去**。

| 场景 | 时长 |
|---|---|
| 表格行展开明细 | 展开 300ms / 收起 200ms（只动高度，不淡） |
| 字段错误说明 | 进出都 200ms |
| 提示条关闭 | 200ms（高度收到 0 并淡出，连间距一起收） |

### 9.2 补位：FLIP

- 先记位置、后算差、再过渡；**只动 `translate`，不碰布局**；
- **走的项先留着**（`data-leaving`）把退场走完，再从页面里拿掉；别的项从它上面滑过去；
- **只有「少了一项」才补位**：加一项、容器变宽、字体到了，各项都直接到位；
- 一排超过 50 项、量不到位置（服务端渲染 / 还没排版 / 藏着）时不做；
- 容器矮了要**量着收**高度，否则还在滑的几项会露出来。

选择规则：**横排、会换行的用补位（FLIP）；竖着的一列用收起。**

### 9.3 跟手的不加过渡

拖动、滑动手势进行中，位置必须贴着指针——**加过渡会让东西追着手指跑**。
过渡只给「跳过去」的变化：按键、点一下、外部改值。

## 10. 选中指示的滑动

几项里选一项时，选中的底/粗条**不是「在这消失、在那出现」，而是同一块东西滑过去**：换的是位置，东西没换。

| 控件 | 指示 | 怎么动 |
|---|---|---|
| 分段选择 | 选中段的墨色底 | 沿轨道滑；各段等宽，只走位置 |
| 页内目录 | 引线上 3px 粗条 | 沿引线滑，长度跟着那项高度变 |
| 页签胶囊 | 选中项的墨色底 | 滑过去，宽度跟着变；盖在路过胶囊的轮廓线上 |

**时长是 200ms `ease-standard`，不是 300ms**：并排比过，300ms 时文字先反过来、墨块晚 100ms 才到。
状态（`aria-checked` 等）与字色在选中那一刻就变，**不等它滑到**。

三条边界：**只有「换了一项」才滑**（首次到位、同项挪位置、容器变宽都直接到位）；
**从没有到有是原地淡入**（不从上一个位置滑来）；**量不到位置就照旧**（永远有一帧有选中态）。

## 11. 标志性动画清单

| 工具类 | 内容 | 用途 |
|---|---|---|
| `animate-flicker` | 三次短闪后点亮，**600ms** | 大图、媒体、标题块入场 |
| `animate-fill` | `scaleX(0) → scaleX(1)`，600ms | 进度条、色块充填（`transform-origin: left`） |
| `animate-scroll-hint` | 下坠 1.5rem 并淡出，循环 | 滚动提示 |
| `animate-breathe` | 缩放 1 → 1.2 → 1，循环 | 提示点、等待态 |
| `animate-marquee` | 平移 −50% 后停顿，循环 | 巨字跑马灯、过长单行 |
| `animate-spin` | 匀速，1 秒一圈 | 加载指示 |
| `animate-spin-slow` | 同一关键帧，60 秒一圈 | 刻度圆环 |
| `animate-blink` | 硬切明灭 | 输入光标、录制指示 |
| `animate-indeterminate` | 平移自身宽度 150% 再返回，1.2s 一程，循环 | 不确定进度（块宽 = 轨道 40%） |
| `animate-pulse` | 不透明度 1 → 0.6 → 1，2s，循环 | 骨架明度往返 |
| `animate-shift-in` | 从偏移处淡入归位，300ms | 错开入场、页头、月历翻月 |
| `animate-wipe-in` | `clip-path` 从左往右露出，300ms | 色带、面积图（600ms） |
| `animate-bracket-in` | 八段短线从角顶点伸到满长，200ms | 角括号出现 |
| `animate-slide-in` / `turn-in` / `fade-in` | 滑入 / 转正 / 淡入，各 300ms | 分节标题三段 |

三条使用规则：

1. **闪烁**：不透明度时间线 `0 → .5 → 0 → .5 → 0 → .5 → 0 → 1`，三次落在 10% / 20% / 40%——
   前两次挨得近、第三次隔得远，模拟**设备通电时的不稳定**；只用于入场、只播一次、**同一视口同时只让一处闪**，
   不用于文字段落与可交互控件；
2. **跑马灯**：内容复制一份首尾相接，匀速到 −50% 后**停顿**（80%–100% 静止）——停顿让它像机械装置而不是无休止滚动；
   要能停（悬停/焦点暂停），且系统开「减少动态效果」时不动、不显示副本；
3. **旋转**：常规 1s 一圈，刻度环 60s 一圈——**慢到几乎不动**才是仪表。

## 12. 开屏页三段式（全库唯一「为了播完而等」）

| 阶段 | 做什么 | 时间 |
|---|---|---|
| **充填** | 进度每变一次，条长、读数位置、读数数字、底图模糊**一起**补间 | 每次 0.5s |
| **铺满** | 全部就绪后等条走满，黄色从左往右盖过整屏，先慢后快 `cubic-bezier(1, 0, 0.7, 1)` | 等 0.5s + 走 0.6s |
| **淡出** | 停一下，整层不透明度降到 0，露出页面；页面自己的入场这时才起 | 第 1.4s 起，走 1s |

从就绪到完全消失 **2.4 秒**。要素：近黑底 `#141414`、**贴左缘**的黄色进度条、大号百分比跟着条的末端走（数字与 `%` 两种字号）、画面偏右是标志与标语。

> 简化版 `Loader`：数字与标语在左下、底部一根横条，就绪后整块**向上滑出 600ms `ease-emphasis`**，
> 一开始退场就放开页面，**不为了播完动画而拖延**。

## 13. 减少动态效果（硬规则）

全局降级：**所有动画与过渡的时长压到接近 0、延迟归零、循环动画只播一次。**

四条容易漏的细节：

1. **延迟必须归零**，否则错开的入场会变成「一项一项蹦出来」，比动着进来更扎眼；
2. **降级后必须停在终态**（`animation-fill-mode: both`），不能停在透明或屏幕外；
3. **状态变化不能只靠动效表达**：页签选中除了位移还有底色变化；
4. **脚本驱动的动效要自己查**：逐帧算的滚动数字直接用终值，平滑滚动直接跳；
   视图过渡在系统开启时直接切。

云游戏页是一个现成样本：18 条 `prefers-reduced-motion` 规则把入场压到 `0.01ms`、延迟归零、只播一次，停在终态；
侧栏与顶栏指示的滑动、加载层的过渡直接关掉。

## 14. 宜 / 忌

| 宜 | 忌 |
|---|---|
| 默认 `duration-base` + `ease-standard`，不确定就不调 | 弹跳、回弹、果冻式缓动 |
| 用 `transform` 与 `opacity` 做动画 | 悬停时放大卡片、上浮加阴影 |
| 让新元素的出现伴随旧元素的让位 | 元素持续漂浮、呼吸、发光（提示点除外） |
| `:hover` 套 `@media (hover: hover)`，避免触屏粘住悬停态 | 每张卡片都带入場动画，或每次滚动都重播 |
| 跟手的位置**不加**过渡 | 用动效拖延用户：超过 0.6s 要理由 |
| 给跟手交互留即时反馈（按下 50ms） | 给拖动中的滑块、被手指带着走的抽屉加过渡 |

## 15. 落到 MirrorpondHUD

### 15.1 现有能力：项目已经有一整套动效档位

[`src/Ui/CardMotion.cs`](../../src/Ui/CardMotion.cs) 把卡片动效集中成四档：

| 档位 | 布局补位 | 显隐 | 位移 | 缓动 | 气质 |
|---|---|---|---|---|---|
| `Current`（默认） | 180ms | 160ms | 8px | 三次 ease-out | 偏产品 |
| `Cut` | 90ms | 80ms | 0 | **线性** | 硬切 |
| **`Industrial`** | **120ms** | **110ms** | **2px** | 三次 ease-out | **最接近终末地** |
| `Off` | 0 | 0 | 0 | — | 即时 |

其它已有能力：

- **`ReduceMotion` 一票否决**（`CardMotion.Enabled` 与循环特效同时受控），且截图 / `--selftest` 会强制关闭；
- **循环特效**五种：`None / Breath / Scanline / Pulse / Contour`，时长夹在 600–20000ms、幅度 0.02–0.8，**默认关闭**；
- `Contour` 循环约 30fps 重算几何（后台算、UI 线程只提交冻结结果）；`Breath` / `Pulse` 是合成器动画，无每帧托管分配；
- `OverlayIntro` 是**打字机式**启动动画（20ms 一拍、速度由 `Behavior.TypeSpeedMs` 控制）。

> **2.39.0 落地**：设置页动效档位按 **优雅 → 标准 → 简短 → 无** 排列，
> 分别对应内部 `Current / Industrial / Cut / Off`；循环效果的 `Pulse` 新增 1–8px 描边粗细，
> `Scanline` 新增 1–10px 横线粗细，均放在「外观 → 动效」并按当前循环效果上下文显示。
> 设置页自身支持 Endfield 暗色 / 浅色两套调色板，与卡片叠层主题互不影响。
>
> **2.41.0 落地**：等高线速度基准改为 **1.0x = 10 秒 / 形变周期**（2.0x = 5 秒、0.5x = 20 秒），
> `StyleSettings.ContourPeriodSeconds` 与运行时相位推进共用这一基准；卡片滑入 / 滑出方向新增
> **`Follow`（跟随对齐）**，取 `CardLayoutCoordinator` 已解析的整叠左 / 右对齐，避免每张卡各猜方向。
> 设置页卡片拖动时，跟随层改为**标题栏折叠快照**，源卡 110ms 淡出、140ms 收成标题栏，
> 其它卡片按动效档位（180 / 120 / 90ms）平移让位。
>
> **2.42.0 落地**：信息与文本卡新增「粒子聚字」文字动效。它把当前文字快照采样成
> 350–1800 个点，粒子从文字外侧收拢，约 1.05 秒后淡回真实文字并**停表**。
> 触发条件是“文字骨架”变化（数字归一成 `#`）：指标 / 时钟的数字刷新不重播，
> 预设、星期、按键名等真实文字变化才播放；`ReduceMotion`、`Off` 档、截图模式都不会启动。
>
> **2.43.0 调整**：粒子默认**就近分配目标**并跨播放保留位置，只改一个字符时不会整句重新散开；
> 收敛结束直接切回清晰文字（瞬时凝固），不再保留 1 秒粒子帧或淡出。
> 粒子大小 / 数量 / 速度 / 就近分配 / 轮廓采样均可在「动效 → 粒子聚字」下调整；
> 文字颜色默认白色，粒子跟随文字颜色。

### 15.2 与规范的四点差异

| # | 现状 | 规范 | 影响 |
|---|---|---|---|
| 1 | 显隐**进出对称**（110/110） | **进 300 / 出 200**（约 1.5:1） | 退场显得拖，卡片消失时多挡一拍 |
| 2 | 没有独立的「状态记号」时长 | 记号一律 **200ms** | 勾、点、角括号只能借显隐档，偏快或偏慢 |
| 3 | `CardStatus` 的转圈是**盲文点阵**（90ms 换帧） | 加载用**匀速旋转**或**不确定进度色块** | 盲文点阵不属于这套语汇，破坏工业感 |
| 4 | 悬停换色是**瞬时**（`OnRender` 里直接换 brush） | 悬停换色 **200ms** | 少了「按下去的厚实感」，但也不算错（50ms 即时档可接受） |

> 第 1 条最值得改：**退场比进场快**是这套语言里最容易被感知的细节，几乎零成本却立刻「像」。
> 第 4 条优先级最低 —— 瞬时换色属于 `duration-instant` 的合法用法，规范自己也把 50ms 留给「按下的即时反馈」。

### 15.3 建议（按视觉收益排序）

| # | 建议 | 具体做法 |
|---|---|---|
| 1 | **主题默认用 `Industrial`** | `.mptheme` 写 `motion.profile = "Industrial"`，已在 [`endfield.md`](endfield.md) 的两套主题里生效 |
| 2 | **改成进出不对称** | `ShowOffset` 保留 2px；`ShowDurationMs` 120、`HideDurationMs` 80（≈1.5:1）。`Off` / `Cut` 不动 |
| 3 | **加一个 200ms 记号档** | `CardMotion.MarkMs = 200`；勾、状态点、角括号、进度块改用它。它不随 profile 变（记号本来就该稳） |
| 4 | **转圈换成不确定进度块** | `CardStatus` 的 Busy 态改成一条 **40% 宽、1.2s 一程**的左右平移色块（`animate-indeterminate`），比盲文点阵更工业 |
| 5 | **入场只播一次、整组 ≤600ms** | 启动时卡片依次出现：错开 100ms、最多 6 张、全组 ≤600ms；**能点的卡片不做位移入场** |
| 6 | **循环只留三种且默认关** | `Breath`（等待态）、`Scanline`（扫线）、`Contour`（等高线）；**每屏最多一处**；`LoopEffect` 保持 `None` 为默认 |
| 7 | **在打字机动画外添加擦除动画** | `OverlayIntro` 现在是逐字打，规范里没有对应手法；预算够的话改成 `wipe-in` 300ms（或保留打字但用 `ease-out` 收尾） |
| 8 | **悬停补 200ms** | 给 `CardButton` 的 `_hoverFill` / `_pressFill` 加 `ColorAnimation`（200ms / 50ms），可达但优先级最低 |

### 15.4 性能红线（项目已有结论，别踩回去）

- 卡片动效走 `OverlayWindow` 的 15ms 帧调度；**不要在 UI 线程做逐帧循环**；
- `ReduceMotion` 是**一票否决**，包括循环特效与截图模式。

### 15.5 验收清单

1. 所有交互反馈都在 0.3s 内结束，没有超过 0.6s 的过渡（入场除外）；
3. 悬停只换色——**不放大、不上浮、不加重阴影**；
4. 退场比进场快（1.5:1）；
5. 状态记号有过渡，且**状态不只靠动效表达**；
7. 开「减少动态效果」后：时长归零、延迟归零、**停在终态**、跑马类静止在起点；
8. 拖动 / 跟手操作**不加**过渡。
